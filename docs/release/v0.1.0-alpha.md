# Go Go HarmoniYo v0.1.0-alpha

The first playable alpha of **Go Go HarmoniYo**, a party rhythm game. A PC shows the game on the
TV, and 1–4 people ring bells with their phones: hold the phone like a handbell and swing it
when your bell reaches the line. Nothing to install on the phones; they scan a QR code.

This is an **alpha** for family and friends, so expect rough edges. Please report what you
find in [Issues](https://github.com/dcuccia/go-go-harmoniyo/issues). All changes are in the
[CHANGELOG](https://github.com/dcuccia/go-go-harmoniyo/blob/main/CHANGELOG.md).

## How to play

**Windows, no install (the zip attached below):**

1. Download `go-go-harmoniyo-0.1.0-alpha-windows-x64.zip`. Optionally check it against
   `SHA256SUMS.txt` (`certutil -hashfile <zip> SHA256`).
2. Right-click the zip → *Extract All…*, open the `GoGoHarmoniYo` folder, and double-click
   `Play Go Go HarmoniYo.cmd`.
3. Windows warns that the app isn't signed ("Windows protected your PC"): click *More info* →
   *Run anyway*. If the firewall asks, tick *Private networks* and click *Allow access*.
4. The game opens in the browser. Drag it to the TV and press F11. Phones scan the QR code.

`README.txt` in the folder explains the Windows prompts, the options and how to remove the game.

**From a clone (Windows, macOS or Linux; for developers):** install
[Node.js 22+](https://nodejs.org) and, preferably,
[cloudflared](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/)
(`winget install --id Cloudflare.cloudflared` on Windows), then:

```
git clone https://github.com/dcuccia/go-go-harmoniyo.git
cd go-go-harmoniyo
npm start
```

`npm start` checks the setup, installs, builds and starts the game, and opens it in the browser.
`npm start -- --check` runs the checks only; `npm start -- --help` lists the options.

**How phones connect:** with internet, the QR is a Cloudflare tunnel address. It has no
certificate warning and works on any network. Phones on the same Wi-Fi as the PC then switch to a
direct link. Without internet, or if the tunnel isn't ready within 60 s, the QR shows the PC's
Wi-Fi address instead: phones must be on the same Wi-Fi, and each shows a one-time certificate
warning. `--lan-only` keeps everything on your network; `--tunnel` uses only the tunnel. While
phones use the tunnel, game traffic passes through Cloudflare's servers.

## What's in it

- **16 public-domain Christmas carols**, each in a full (2–3 minute) and a short form. None has
  been proofread by the owner yet ([#30](https://github.com/dcuccia/go-go-harmoniyo/issues/30));
  see *Known issues*.

  | Song | Source | Proofread by the owner |
  |---|---|---|
  | Deck the Halls | Self-encoded lead sheet (CC0); notes fixed in #57 | Not yet (#30) |
  | Jingle Bells | Self-encoded lead sheet (CC0); notes fixed in #57 | Not yet (#30) |
  | Joy to the World | Self-encoded lead sheet (CC0) | Not yet (#30) |
  | Silent Night | Self-encoded lead sheet (CC0) | Not yet (#30) |
  | We Wish You a Merry Christmas | Self-encoded lead sheet (CC0) | Not yet (#30) |
  | Away in a Manger | Mutopia Project hymnal setting (SATB) | Not yet |
  | Good King Wenceslas | Mutopia Project (four voices) | Not yet |
  | Hark! The Herald Angels Sing | Mutopia Project hymnal setting (SATB) | Not yet |
  | In the Bleak Midwinter | Mutopia Project hymnal setting (SATB) | Not yet |
  | It Came Upon the Midnight Clear | Mutopia Project hymnal setting (SATB) | Not yet |
  | O Come, All Ye Faithful | Mutopia Project hymnal setting (SATB); refrain fixed in #68 | Not yet |
  | O Come, O Come, Emmanuel | Mutopia Project hymnal setting (SATB) | Not yet |
  | O Little Town of Bethlehem | Mutopia Project hymnal setting (SATB) | Not yet |
  | The First Noel | Mutopia Project hymnal setting (SATB) | Not yet |
  | The Holly and the Ivy | Mutopia Project (melody only) | Not yet |
  | What Child Is This | Mutopia Project hymnal setting (SATB) | Not yet |

  AI agents proofread the five self-encoded lead sheets and compared every melody with a
  public-domain hymnal edition (#68). That doesn't replace the owner's proofread.
- **Difficulties:** Super easy, Easy, Medium, Hard.
- **1–4 ringers.** Arrangements: Balanced (role-aware parts), Chord split, By range. The TV rings
  bells that don't fit on the phones.
- **Lobby:** a seating chart (drag players onto parts, or phones pick their own), drop-in joining
  mid-song with a corner QR, practice speed 50–100 %, and backing track and sound-effect settings.
- **Phones:** bells coloured by pitch class; touch a zone to pick a bell, swing to ring; fast
  repeated rings (Normal or Quick sensitivity).

## Known issues

- **The Windows program isn't code-signed.** SmartScreen shows "Windows protected your PC":
  click *More info* → *Run anyway*. **Smart App Control** (on by default on some new Windows 11
  PCs) blocks unsigned apps and can't be overridden per app: use a clone and `npm start` instead.
  The firewall prompt names "Node.js JavaScript Runtime" (the engine inside the program).

  Code signing: Windows builds are being moved to free code signing by
  [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org);
  this release is unsigned. See the
  [code signing policy](https://github.com/dcuccia/go-go-harmoniyo#code-signing-policy).
- **The carols aren't proofread by the owner yet** and may contain wrong notes
  ([#30](https://github.com/dcuccia/go-go-harmoniyo/issues/30)).
- **iPhone wasn't tested directly.** An iPad Pro (same WebKit engine) was. Please report iPhone
  problems ([#34](https://github.com/dcuccia/go-go-harmoniyo/issues/34)).
- **Tunnel mode needs internet** on the PC. Without it, phones must be on the same Wi-Fi as the
  PC, and each shows a one-time certificate warning. Guest Wi-Fi often keeps phones away from the
  PC. Help next to the QR on the TV is planned
  ([#26](https://github.com/dcuccia/go-go-harmoniyo/issues/26)).
- Up to 4 ringers ([#33](https://github.com/dcuccia/go-go-harmoniyo/issues/33)). Swing to ring
  only; a Tap mode is planned ([#20](https://github.com/dcuccia/go-go-harmoniyo/issues/20)).
- A phone that reconnects mid-song loses the next-bell glow
  ([#36](https://github.com/dcuccia/go-go-harmoniyo/issues/36)).
- One audio/video offset for the whole TV, not per phone
  ([#37](https://github.com/dcuccia/go-go-harmoniyo/issues/37)).
- The TV host was tested on Windows 11 only. The zip is for Windows x64; on macOS and Linux, use a
  clone.
