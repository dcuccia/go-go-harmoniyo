# Name check: "Go Go Harmonio" and "Go Go HarmoniYo"

- Date: 2026-10-23
- Issue: [#13](https://github.com/dcuccia/handbell-hero/issues/13)
- Candidates: **Go Go Harmonio** (primary, mascot "Harmonio") and **Go Go HarmoniYo** (owner's
  fallback, mascot "HarmoniYo" or "Yo"; "YoYo" is a family nickname)
- Draft brand guide: [docs/design/brand.md](../design/brand.md)

> **Not legal advice.** This is a knockout screen from public databases and web searches done on
> one day. It is not a full clearance search or an attorney opinion. Database coverage has gaps,
> and unregistered (common-law) use is only partly visible on the web. Get counsel before filing
> or making a commercial launch.

## Summary

Neither candidate has a blocker. **Go Go HarmoniYo is the cleaner mark**: it's a new word with
no trademark, app, web or handle hits anywhere we looked, and every domain and handle is free,
including `harmoniyo.com`. **Go Go Harmonio is viable but scores yellow in five places.** Its
distinctive word, "Harmonio", is already in use:

- Boehringer Ingelheim holds HARMONIO for medical research (class 42).
- harmonio.io is a live personalized-song business.
- A Thai music channel uses @harmonio on YouTube.
- In Spanish, Italian and Portuguese, "harmonio/armonio/harmónio" is the ordinary word for a
  harmonium.

Harmonio also sits one letter away from HARMONIX (Harmonix Music Systems, owned by Epic Games),
a strong mark for music video games.

Green = no issue found. Yellow = manageable with the brand rules or a little care. Red = blocker.

### Recommendation

1. **Either name can go ahead. Neither needs to be dropped.**
2. **We lean toward Go Go HarmoniYo** if the owner wants to file a trademark, own the mascot name
   on its own, or launch on app stores. It gives:
   - a unique coinage, so knockout searches stay clean;
   - every domain and handle, including the bare mascot name;
   - more distance from HARMONIX;
   - a gender-neutral mascot name (the brand guide's women-forward options work more naturally);
   - a real family story.

   It costs a medial capital that people will sometimes lowercase.
3. **Go Go Harmonio** is fine if the name always appears in full and we don't need to own
   "Harmonio" on its own. Other parties already use the bare word in music (harmonio.io, the Thai
   YouTube channel), so the mascot name stays a character name, not a separate brand.
4. **Does "-Yo" distance the name from the marks?**
   - **HARMONIX:** yes. "-nix" and "-nee-yo" differ in sight and sound, and the ending is the
     part people remember.
   - **HARMONIA:** somewhat. The ending differs, but the shared HARMONI- stem remains.
   - **HARMONIO:** visually only. Spoken aloud, "HarmoniYo" and "Harmonio" sound almost the same.
     That matters little, because Boehringer's mark covers unrelated goods.
5. **Trademark filing.** Not needed for the holiday release (friends and family). Before a public
   app-store launch, consider a US intent-to-use application (§1(b)) for the full phrase as a
   standard-character mark:
   - **Class 9:** downloadable game software. This is the core class.
   - **Class 41:** providing online non-downloadable games, and entertainment/education services
     in the field of music. This is the core class.
   - **Class 28:** only if we sell physical controllers or toy instruments.
   - **Class 15:** only if we sell real handbells.
   - **Class 42:** only if we offer SaaS/hosting. Note Boehringer's HARMONIO there if we pick
     Harmonio.

   File the mascot name separately later, if ever. Get a full clearance search and counsel first.
   Madrid or EUIPO filing can wait until EU distribution. Fees change; check the
   [USPTO fee schedule](https://www.uspto.gov/learning-and-resources/fees-and-payment/uspto-fee-schedule).
6. **Owner action, low cost, before any public mention.** Reserve these (we registered nothing):
   - the chosen name's `.com` (and optionally `.game`/`.app`);
   - a GitHub org;
   - the npm org/scope;
   - YouTube, TikTok, X, Bluesky and Instagram handles;
   - a NuGet prefix reservation if we publish .NET packages.

   For Harmonio: `gogoharmonio`. For HarmoniYo: `gogoharmoniyo` plus `harmoniyo`.

## 1. Trademarks

### Method

- **USPTO:** the Trademark Search system ([tmsearch.uspto.gov](https://tmsearch.uspto.gov)). We
  sent its own Elasticsearch query from a browser session on the site, querying the
  `wordmark`/`wordmarkPseudoText` fields with wildcards (`HARMONI*`, `HARMONIO*`, `GOGO`,
  `"GO GO"`). Then we filtered to live marks in classes 009/028/041/042, with goods that mention
  games, music, toys, entertainment or software. There's no public unauthenticated API; plain
  scripted POSTs are refused (HTTP 405).
- **EUIPO and national offices:** [TMview](https://www.tmdn.org/tmview) "contains" search. It
  covers EUIPO, WIPO Madrid and 70+ national offices.
- **WIPO:** [Global Brand Database](https://branddb.wipo.int/en/similarname), brand-name search
  with the Embedded, Phonetic and Fuzzy strategies.

To reproduce by hand, run these searches:

- In USPTO tmsearch: `HARMONIO`, `HARMONIO*`, `"GO GO HARMONIO"`, `GOGO HARMONIO`, `HARMONIYO`,
  `HARMONIX`, `HARMONIA`, `HARMONI*`, `"GO GO"` and `GOGO`. Set the status filter to Live and
  the class filter to 009, 028, 041 and 042.
- In TMview: Trade mark name "contains" `harmonio`, `harmoniyo`, `go go harmonio` and
  `harmonix`.
- In WIPO GBD: brand name `harmonio` and `harmoniyo`, with each strategy (Embedded, Phonetic,
  Fuzzy).

### "GO GO" / "GOGO" in classes 9/28/41

We found 82 live "GO GO" and 34 live "GOGO" marks with game, music or toy goods. Examples:

- **Games:** GO! GO! CORY CARSON and GO! GO! SMART FRIENDS/WHEELS (VTech), GO-GO HERO (Century
  Games, class 9/41 game software, reg. 8245631), GO-GO TOWN! (video games), GOGO! BLAST (games),
  GO GO POWER RANGERS, GO GO RACERS (JAKKS), GOGO MY DANCIN' PUP (Hasbro).
- **Music:** GO-GO'S (the band, classes 9/25/41).
- **Other:** GOGO (Gogo Business Aviation, in-flight connectivity) and GOGOSING (pending, 9/42).

With this many coexisting marks, "Go Go" is a weak, diluted element. Consumers will rely on the
second word to tell brands apart. That's why the full name must always be used. GO-GO HERO is
also one more reason never to pair the name with "Hero".

### Likelihood of confusion (qualitative, not legal advice)

These are the usual USPTO *DuPont* factors:

- **Similarity of the marks** (sight, sound, meaning, overall impression):
  - Go Go Harmonio vs HARMONIX: moderate. They share HARMON-, and "Harmonio" and "Harmonix"
    differ only in the ending. The leading "Go Go" and the two-word rhythm help.
  - Go Go HarmoniYo vs HARMONIX: lower. "-Yo" gives a new syllable and meaning.
  - Either name vs HARMONIO (Boehringer): high in sound, but see the next factor.
- **Relatedness of goods and channels:**
  - HARMONIX covers exactly our goods (music video games, instrument-controller toys, online
    games). That's the main risk factor, so keep the marks clearly apart.
  - Boehringer's HARMONIO covers immuno-oncology research services. Those are unrelated, with
    separate buyers and channels, so the risk is low.
  - harmonio.io sells personalized songs. That's related to music, but it isn't a game. The risk
    is low to moderate, mostly for search and handle confusion, not for the trademark.
- **Strength of the prior mark:** Harmonix is a well-known studio (Rock Band, Dance Central,
  Fortnite Festival), so its mark gets a wider scope. "Go Go" is weak (crowded).
- **Purchaser care:** low for a free family or classroom game, which slightly increases risk.
- **Intent and trade dress:** we choose original visuals ([visual identity](../design/visual-identity.md),
  [ADR-0008](../decisions/0008-assets-ip-and-attribution.md)) and don't use "-ix"/"Hero" naming.
  That lowers the risk.

## 2. App stores

- **Apple:** iTunes Search API (`entity=software`, plus `macSoftware` and `iPadSoftware`), US, GB
  and DE storefronts. Terms: `go go harmonio`, `gogo harmonio`, `harmonio`, `harmoniyo`,
  `go go harmoniyo`.
  - No app is titled or published as Harmonio, Go Go Harmonio or HarmoniYo.
  - Results are harmonium instrument apps (Harmonium Plus HD, Harmonium – Official App, …),
    "Harmonize Music" and "Harmonizr".
  - Searching `harmonix` finds unrelated apps: "Harmonix: Nature Sounds Mixing", "Harmonix
    (Bloobirds)" and "HarmoniX Corp" (AI music generator, DE store).
- **Google Play:** web search (`/store/search?q=…&c=apps`, en-US). No app is titled Harmonio or
  HarmoniYo. Results are harmonium apps plus "Harmono Piano" (`app.harmono`), "Harmoni" (wellness
  apps) and "GOGO LIVE".
- **Discoverability:** both stores treat "harmonio" and "harmoniyo" as misspellings of
  "harmonium". At launch, put the full name and "handbell" or "rhythm game" in the title or
  subtitle.

## 5. Web and cultural associations

- **No existing product** was found for "Go Go Harmonio", "GoGo Harmonio", "HarmoniYo" or
  "Go Go HarmoniYo" in web searches.
- **"Harmonio" is a dictionary word** for the harmonium in Portuguese ("harmónio" in pt-PT,
  "harmônio" in pt-BR), and close to Spanish and Italian "armonio". The music link is pleasant,
  but on its own the word is less distinctive. Cortizo (Spain/Portugal) sells "Harmónio" folding
  doors.
- **The "-o" ending reads masculine** in Spanish, Italian and Portuguese. That matters for the
  women-forward mascot options in the brand guide. "HarmoniYo" and "Yo" are gender-neutral.
- **"Go-go":**
  - Washington, D.C. go-go music (a funk subgenre, the official music of D.C. since 2020).
  - 1960s go-go dancing; go-go dancing in clubs.
  - The Go-Go's band.
  - Gogo (in-flight Wi-Fi).
  - "Go Go Power Rangers".
  - "Inspector Gadget's" catchphrase "Go Go Gadget".

  All of these are upbeat and none is a blocker. Keep the brand clear of go-go-dancer imagery
  (classroom audience).
- **"Gogo" in other languages:**
  - French: "à gogo" means galore (positive). "Un gogo" is slang for a dupe (mild, and we always
    write it as two words).
  - Brazilian Portuguese: "gogó" means Adam's apple.
  - isiZulu/isiXhosa and other Southern African languages: "gogo" means grandmother, a respectful
    and warm word. We note it but don't use it as a design hook, to avoid cultural appropriation.
  - Wagogo (Gogo) is a people of Tanzania.
  - Japanese ゴーゴー is just "go go". German: no issue found.
- **"Yo":** Spanish for "I". English greeting. Japanese emphatic particle よ. The yo-yo toy
  ("YO-YO" became generic in the US in 1965). The rapper Yo-Yo. The cellist Yo-Yo Ma: never use
  his name or likeness, and don't write "Yo-Yo" next to music imagery in a way that could suggest
  endorsement.

## 6. What the owner needs to do

1. **Pick** Go Go Harmonio or Go Go HarmoniYo (see the [recommendation](#recommendation)).
2. **Reserve the chosen name's** .com, GitHub org, npm org, NuGet prefix (when we publish) and
   YouTube, TikTok, X, Bluesky and Instagram handles. Nothing was registered by this session.
3. **Before a public app-store launch:** commission a full clearance search and decide on a USPTO
   filing in classes 9 and 41.
4. **After choosing:** move the brand guide from Proposed to Accepted (with an ADR if you like),
   then update the README title, `attribution/credits.json` (`project.name`) and user-facing
   strings. Close [#13](https://github.com/dcuccia/handbell-hero/issues/13).

## Reproduction notes

Run on 2026-10-23 from Windows 11 with PowerShell 7 and a Playwright Chromium session:

- **USPTO:** `POST https://tmsearch.uspto.gov/prod-stage-v1-0-0/tmsearch` (Elasticsearch body,
  `query_string` on `wordmark`), issued with `fetch` from a page on tmsearch.uspto.gov. The page
  carries the site's WAF token.
- **TMview:** `POST https://www.tmdn.org/tmview/api/search/results` with `criteria: "C"`, issued
  from a TMview page.
- **WIPO GBD:** UI form, Embedded, Phonetic and Fuzzy strategies.
- **Apple:** `https://itunes.apple.com/search?entity=software&country=us|gb|de&term=…`.
- **Google Play:** `https://play.google.com/store/search?q=…&c=apps&hl=en&gl=US`, titles parsed
  from the HTML.
- **Domains:** RDAP servers from `https://data.iana.org/rdap/dns.json`. WHOIS for .io and .co.
- **Handles:**
  - GitHub: `gh api users/<name>`.
  - npm: `registry.npmjs.org/<name>` and `/-/org/<name>/package`.
  - NuGet: `azuresearch-usnc.nuget.org/query`.
  - YouTube: `youtube.com/@<name>` (404 means free).
  - Bluesky: `com.atproto.identity.resolveHandle`.
  - TikTok: page `statusCode`.
  - X: HTTP status.
