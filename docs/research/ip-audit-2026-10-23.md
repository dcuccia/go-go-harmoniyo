# IP and license audit — 2026-10-23

Scope: everything on `main` at `7f1f7df`. That covers spikes S1–S5, integrations I1 and I2,
`docs/` (including media), `tools/setup`, CI workflows, and git history for removed assets. This
audit is the evidence for [ADR-0008](../decisions/0008-assets-ip-and-attribution.md). It records
project practice and is not legal advice.

## How it was checked

- **File licenses.** Every tracked file is mapped in `REUSE.toml`. `reuse lint` (reuse 6.2.0)
  reports "compliant with REUSE 3.3": 233/233 files have copyright and license info.
- **Assets.** We listed every file with a media, music, chart, font or model extension, plus
  chart JSON and `song.ini`. All 69 are claimed by an entry in
  [`attribution/register.json`](../../attribution/register.json)
  (`node tools/licensing/attribution.mjs`).
- **Mutopia files.** We downloaded them from mutopiaproject.org and compared SHA-256. The `.ly`
  files match after LF normalization (the git working tree uses CRLF). The `.mid` files are
  byte-identical. Each license was read from the piece page and from the `.ly` header.
- **Dependencies.** We read the `license` of every package in each `package-lock.json` (225
  package versions across 4 npm projects) and scanned MSBuild files for `PackageReference`
  (`node tools/licensing/license-gate.mjs`).
- **Copied code and embedded media.** We grepped spike sources for third-party URLs, fonts,
  embedded media (`base64`, `data:audio`), shader provenance ("shadertoy"), "adapted from" /
  "copied" notes, YARG namespaces, and franchise names.
- **Images.** We viewed the committed screenshots (S4, I1, I2).
- **Upstream licenses.** We checked YARG and YARG.Core with the GitHub API: both are
  LGPL-3.0, and their READMEs say "(or later)".
